# Команда реализации проекта

Оптимальный состав — **6 ключевых сотрудников в штате** + **7-й элемент на аутсорс/партнерство** для полевых работ.

---

## 1. CEO / Product Owner
**Фокус:** Стратегия, фундаментрадинг, B2B/B2G продажи, управление продуктом.

### Функционал
- Разработка стратегии выхода на рынок и юнит-экономики hardware-проекта.
- Привлечение инвестиций на долгий цикл R&D (Pre-Seed / Seed).
- Построение продаж в B2G (экомониторинг, госзакупки) и B2B (ветрогенерация, строительство, недропользование).
- Преодоление бюрократических барьеров при получении разрешений на установку датчиков на ООПТ.
- Управление продуктовым бэклогом и приоритетами команды.

### Ключевые компетенции
- Опыт запуска hardware/IoT или deep-tech стартапов.
- Понимание CAPEX/OPEX «железных» проектов.
- Навыки B2B/B2G продаж и переговоров с экологическими фондами.

---

## 2. CTO / Lead Hardware & Edge Engineer
**Фокус:** Физический гаджет, энергопотребление, Edge-вычисления, надежность.

### Функционал
- Проектирование аппаратной части: выбор MCU/DSP, разработка PCB, схемотехника.
- Реализация ultra-low-power архитектуры устройства.
- Embedded-разработка прошивки (C/C++/Rust), интеграция с NN1 на Edge.
- Разработка всепогодного корпуса, защита от вандализма и животных.
- Решение проблемы дрейфа АЧХ микрофона (калибровочный модуль).

### Ключевые компетенции
- Глубокое знание embedded-разработки и проектирования PCB.
- Экспертиза в ultra-low-power design.
- Опыт работы с STM32, ESP32-S3, Nordic, DSP и NPU.
- Понимание ограничений Edge AI (квантование, TFLite Micro).

---

## 3. Lead ML Engineer / Audio AI
**Фокус:** Ядро продукта — нейросети NN1, NN2, NN3. Обработка аудио.

### Функционал
- Разработка и обучение моделей детекции (NN1) и классификации (NN3).
- Исследование и внедрение алгоритмов разделения источников (NN2) — преимущественно для облачного пайплайна.
- Реализация Open-Set Recognition для корректной обработки неизвестных видов.
- Аугментация данных с учетом диалектов, сезонности и контекста.
- Оптимизация моделей для Edge и Cloud-инференса.

### Ключевые компетенции
- Специализация именно на аудио и спектрограммах (librosa, torchaudio, audio transformers).
- Опыт в Source Separation и anomaly detection.
- Навыки работы с несбалансированными датасетами.

## 4. Lead Backend & Data Engineer
**Фокус:** Облачная инфраструктура, пайплайны данных, телеметрия.

### Функционал
- Разработка API для приема данных с гаджетов (MQTT, LoRaWAN backend).
- Построение пайплайнов пакетной обработки аудио в облаке (NN2, NN3).
- Проектирование хранилища геоданных и временных рядов (PostGIS, TimescaleDB).
- Обеспечение масштабируемости системы под растущую сеть устройств.
- Интеграция с картографическим фронтендом.

### Ключевые компетенции
- Python (FastAPI) или Go.
- Опыт с IoT-протоколами и очередями (Kafka/RabbitMQ).
- Работа с геоданными и временными рядами.

---

## 5. Lead Ornithologist / Bioacoustics Expert
**Фокус:** Доменная экспертиза, валидация данных, полевые испытания.

### Функционал
- Контроль качества и методологии разметки датасетов.
- Выбор локаций для пилотного развертывания с учетом реальных путей миграции.
- Валидация результатов работы нейросетей на полевых данных.
- Консультации по физике распространения звука в разных биотопах.
- Связь с научным сообществом, орнитологическими фондами, заповедниками.

### Ключевые компетенции
- Профессиональное образование в области зоологии/орнитологии.
- Опыт работы с акустическими регистраторами (AudioMoth, Song Meter).
- Знание птичьих вокализаций и биоакустики.

---

## 6. Full-Stack / GIS Developer
**Фокус:** Клиентский интерфейс, интерактивные карты миграции, дашборды.

### Функционал
- Разработка веб-платформы с интерактивными картами миграции.
- Визуализация больших массивов пространственно-временных данных.
- Создание дашбордов для B2B/B2G клиентов (экологический комплаенс).
- Поддержка API для карт и аналитики.

### Ключевые компетенции
- Frontend: React/Vue, Mapbox GL, Leaflet, Cesium.
- Опыт визуализации геоданных без потери производительности.
- Базовые навыки Backend для поддержки API.

## 7. Field Operations & Legal (Аутсорс / Партнерство)
**Фокус:** Физическое развертывание, обслуживание, юридическое сопровождение.

### Функционал
- Физический монтаж гаджетов на деревьях/мачтах.
- Регулярное обслуживание: чистка мембран, замена батарей, калибровка.
- Взаимодействие с местным населением, охраной ООПТ.
- Получение юридических разрешений на установку оборудования.
- Защита устройств от вандализма и краж.

### Формат сотрудничества
- Партнерство с заповедником/НКО или контракт с полевым инженером-волонтером.
- Не требует включения в штат на старте, но критичен для успешного пилота.

## Резюме по формированию команды
- **Критические роли для найма:** ML-инженер по аудио и орнитолог. Требуется нишевый опыт в аудио-аналитике, а не общие Data Science навыки.
- **Режим работы связки ML + Bio:** биолог объясняет физику звука, ML-инженер переводит это в математику — постоянный контр-чек на всех этапах.
- **Кросс-функциональность:** на ранней стадии каждый сотрудник должен быть готов выходить за рамки своей роли (например, CTO участвует в полевых тестах, ML-инженер помогает с разметкой данных).
