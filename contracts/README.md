# Контракты

Утверждённые границы между треками. Пока контракт не записан здесь, агент не меняет поля события, API и схему БД в коде.

| Контракт | Статус | Где смотреть |
|---|---|---|
| Окно анализа | действует | `../config/window_config.yaml` |
| Пакет задачи агенту | шаблон | `task-packet.md` |
| Поля телеметрии и события | в спецификации | `../doc_v2/MVP_SPEC.md` §2.1, `../doc_v2/ARCHITECTURE.md` §3 |
| Схема БД | ещё не перенесена в миграции | `../doc_v2/AI_AGENTS_SPEC.md` §4.1 |
| OpenAPI | ещё не утверждён | появится вместе с сервисом в `cloud/` |

`event_id` — UUID v4, создаётся на устройстве и проходит MQTT, REST и таблицы без подмены.
