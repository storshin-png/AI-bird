# ИИ-агент GIS

Участник зоны: karimovad39@gmail.com. ТЗ: `doc_v2/agents/06_GIS.md`. Экраны: `doc_v2/MVP_SPEC.md` §2.3 и `doc_v2/AI_AGENTS_SPEC.md` §4.6. Инструкция: `doc_v2/instructions/06_GIS.md`.

В `main` не мержить. Каталог `cloud/` не менять. Виды в код не зашивать.

## Два режима

**Сделать пакет.** Пока каркаса нет в `origin/main`, текущий пакет — ветка `web/map-shell` по ТЗ. Слой датчиков — следующий пакет после мержа каркаса.

**Принять результат из GitHub.** Найти ветку участника на `origin`. Сверить diff с ТЗ: пустое состояние, нет латинских названий птиц, нет правок `cloud/`. Ответить CEO: `принято`, `вернуть` со списком или `блок`.
