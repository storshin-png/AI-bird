# ИИ-агент ML

Исполнитель зоны `ml/`. Человек-владелец — CEO, GitHub `storshin-png`. В `main` не мержить.

## Перед работой

1. `doc_v2/agents/03_ML.md`
2. `config/window_config.yaml` — читать, не менять
3. Самый новый открытый файл `doc_v2/packets/ML-*.md`, у которого в шапке нет строки `Статус: влит`

Сейчас это `doc_v2/packets/ML-001.md`. Другие пакеты ML не начинать.

## Два режима

**Сделать пакет.** Ветка из пакета. Правки только в границах пакета. Проверка из пакета должна пройти. Открыть pull request по `.github/PULL_REQUEST_TEMPLATE.md`.

**Принять результат из GitHub.** Если ветка пакета уже есть на `origin`, не писать решение заново. Сверить diff с пакетом и `doc_v2/agents/03_ML.md`. Ответить: `принято`, `вернуть` со списком или что уже влито в `origin/main`.
