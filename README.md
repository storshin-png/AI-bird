# AI-bird

Акустический мониторинг миграции птиц. Рабочая документация — в `doc_v2/`. Рамка MVP заморожена, календарь и журнал решений — в `doc_v2/IMPLEMENTATION_PLAN.md`.

Удалённый репозиторий: https://github.com/storshin-png/AI-bird.git

## Каталоги

| Каталог | Что внутри |
|---|---|
| `doc_v2/` | Актуальные спецификации, план, роли, инструкции и ТЗ агентов |
| `doc_v1/` | Предыдущая редакция документов, в работу не берётся |
| `config/` | Единый конфиг окна анализа |
| `contracts/` | Границы между треками и шаблон пакета задачи |
| `firmware/` | Прошивка датчика |
| `hardware/` | Схема, корпус, стенд, закупка |
| `ml/` | Нарезка, спектрограммы, обучение |
| `cloud/` | Приём данных, пайплайн, трекинг |
| `web/` | Карта и кабинеты |
| `data/` | Правила датасета; сами записи живут локально |

Люди управляют агентами по `doc_v2/COLLABORATION.md` и открывают pull request. В `main` вливает CEO. На каждый запрос GitHub запускает проверку `ci`.

Как вносить изменения: `CONTRIBUTING.md`.

## Что не коммитится

Виртуальное окружение `Python/venv/`, файлы `.env` и аудио из `Sound sample/`, пока лицензии не записаны в журнале плана.
