# Прошивка

Захват 4 каналов, кольцевой буфер, NN1, оценка направления, запись WAV и пакет LoRaWAN.

Параметры спектрограммы берутся из `../config/window_config.yaml`. Приёмка — у CTO, чеклист в `../doc_v2/roles/02_CTO.md`.

Промежуточный стенд с одним микрофоном: `debug_stand/`. Поток режется окном 2.5 с с базовым шагом 1.0 с, log-mel пишется на SD. Четыре канала, NN1 и LoRaWAN сюда ещё не положены. До прогона на плате тот же расчёт проверяется на WAV.
