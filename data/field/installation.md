# Форма установки

Поля метаданных — `doc_v2/USERFLOW.md` §5.1.
Координаты площадки и виды в форму не вписываются: площадку записывает человек, виды определяет орнитолог.

## Правило закрытия

Без ориентации и четырёх живых каналов установка в пилот не закрывается.
Пустой `orientation_deg` или неживой канал N, E, S или W означает, что датчик на точке пилота не оставляют.

## Четыре канала

| Канал | Живой (да/нет) |
|---|---|
| N | |
| E | |
| S | |

Установка закрыта для пилота, только когда `orientation_deg` заполнен и все четыре канала отмечены живыми.

## Таблица установок

Заполненные бумажные формы человек переносит в `installations.csv`: одна установка — одна строка. Колонки — поля формы и четыре канала (`ch_n_live` … `ch_w_live`, значения `да` или `нет`). Пустые выезды в таблицу не вписываются.

Проверка правила закрытия из корня репозитория:

```text
python data/field/check_installations.py
```

Скрипт показывает, какие установки закрыты для пилота, а какие нет и почему. С `--devices-json devices.json` он пишет данные закрытых установок в формате карточки датчика в облаке, чтобы карточка совпала с бумажной формой.
