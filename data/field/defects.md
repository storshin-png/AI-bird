# Дефектный лист

Изделие, которое не прошло проверку на столе или сломалось на точке, записывается сюда, а не остаётся «на точке без связи» (`doc_v2/roles/07_FIELD_OPS.md`, спринт 7). Разбор электроники — у CTO.

Одно изделие и одна неисправность — одна строка. Новых позиций закупки лист не создаёт: замену согласует CTO по составу варианта 2 (`hardware/STAND.md`, «Гаджеты на стенде»).

| Поле | Что писать |
|---|---|
| `device_id` | Как в карточке установки или на наклейке корпуса |
| Дата | ГГГГ-ММ-ДД, когда неисправность найдена |
| Где найдено | стол / стенд / точка |
| Подсистема | вычисления / звук / связь / питание / память / датчики / время / корпус / плата |
| Что не так | Наблюдение без догадки о причине: «канал W молчит», «нет LoRa-пакетов 2 суток» |
| Каналы N / E / S / W | живой / нет — для подсистемы «звук» |
| Фото | Ссылка или имя файла |
| Действие | снят с точки / не выезжает / заменена деталь / ждёт CTO |
| Решение CTO | Заполняет CTO |
| Закрыто | Дата, когда изделие снова прошло 4 канала и чеклист CTO |

Датчик с открытой строкой в этом листе на точку не уезжает: правило «без ориентации и четырёх живых каналов в пилот не ставится».
