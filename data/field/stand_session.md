# Журнал сессии стенда направления

Чертёж, лучи, дистанции и поля L5 — `hardware/STAND.md`. Этот журнал их не меняет, а записывает, что снято на площадке.
Колонки L5 — `doc_v2/Структура разметки датасета.md` §1.4.

Одна сессия — один лист и строки в двух таблицах: `stand_rays.csv` (лучи) и `stand_session.csv` (снятые отметки). Пустые сессии в таблицы не вписываются.

## Шапка

| Поле | Значение |
|---|---|
| `session_id` | |
| Дата | |
| `device_id` | |
| Канал N совмещён с географическим севером | да / нет |
| Чем проверен север | |
| Кто снимал | |

Если канал N на север не совмещён, у всех записей этой сессии `bearing_quality` будет `ambiguous`.

## Лучи

Для каждого из восьми лучей — свободная длина `L` в метрах. По ней видно, какие отметки снимать (`hardware/STAND.md`, «Дистанции и пропуски»):

| `L` | Снимать |
|---|---|
| короче 5 м | луч не снимается |
| 5–10 м | 5 |
| 10–20 м | 5, 10 |
| 20–50 м | 5, 10, 20 |
| 50 м и длиннее | 5, 10, 20, 50 |

Пропуск пишется в `stand_rays.csv` колонкой `skip_reason` (например, «площадка короче»). Строки отметки для пропущенной дистанции нет.

## Отметки

Одна запись — одна строка `stand_session.csv`:

| Колонка | Кто | Что писать |
|---|---|---|
| `session_id` | полевой инженер | Из шапки |
| `device_id` | полевой инженер | Из шапки |
| `file` | полевой инженер | Имя WAV-файла записи |
| `azimuth_deg` | полевой инженер | Угол отметки по таблице лучей: 0, 45, … 315 |
| `sector` | полевой инженер | Сектор того же луча |
| `distance_m` | полевой инженер | 5, 10, 20 или 50 |
| `num_sources` | полевой инженер | 1 — на стенде звучит один источник |
| `bearing_quality` | **орнитолог** | `good`, `medium`, `poor`, `ambiguous` — после прослушивания |
| `notes` | все | Ветер, посторонний звук, источник не на отметке |

`bearing_quality` полевой инженер оставляет пустым. Орнитолог ставит `good` для отметки чертежа с одним источником и каналом N на север, остальные значения — по таблице в `hardware/STAND.md`.

## Проверка

Из корня репозитория:

```text
python data/field/check_stand.py
```

Скрипт показывает для каждой сессии: снята ли она как стенд, каких отметок не хватает по длине лучей, какие строки противоречат чертежу, у скольких записей ещё нет `bearing_quality`. С `--ml-csv l5.csv` он пишет таблицу «файл / истинный азимут / сектор / дистанция / качество» для передачи ML — только строки с `bearing_quality`.
