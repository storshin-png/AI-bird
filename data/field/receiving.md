# Сверка поставки

Два гаджета. Строки — только подсистемы варианта 2 из `doc_v2/Спецификации/BOM 3 варианта.md`.
Новых позиций закупки в этот лист не добавляют.

Статус каждой ячейки заполняет человек после приезда груза: `есть`, `нет` или `замена`.
Пустая ячейка — груз ещё не сверен.

| Power | LiFePO4 8000 мАч + панель 7 Вт + выделенный MPPT + защита обратного тока | | |
