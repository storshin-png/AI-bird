# Веб

Карта датчиков, пеленги, треки, карточка события, очередь Unknown и экспорт. Экраны — `../doc_v2/MVP_SPEC.md` §2.3. Приёмка — у GIS-разработчика.

Сейчас в каталоге каркас: вход-заглушка и пустая карта. Слоя точек и кластеризации нет. Список видов не зашит: функция возвращает пустой список, источник будет `GET /species`.

Слои собираются на синтетическом GeoJSON и не ждут полевых датчиков.

## Проверка сборки

Из каталога `web`:

```text
npm install
npm run build
```
