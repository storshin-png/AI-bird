# Данные и модели

Скрипты черновика NN1 перенесены из локальной папки `Python/`. Они по-прежнему режут моно и держат копию параметров окна в коде. Подключение к `../config/window_config.yaml` и отказ от жёстких путей — отдельная задача подготовки. В приёмку такие пути не проходят.

Локальное окружение остаётся в `Python/venv/` и в репозиторий не входит.

Зависимости черновика: `requirements.txt`.

Аудиофайлы из `Sound sample/` в репозиторий не коммитятся, пока CEO не закроет лицензии в журнале `doc_v2/IMPLEMENTATION_PLAN.md`.
