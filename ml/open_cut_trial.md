# Пробная нарезка открытых записей

Пакет ML-002, спринт 1 (19.10.2026–30.10.2026).

Вход — локальная папка `Sound sample`. Сырое аудио, фрагменты и спектрограммы в репозиторий не входят.

## Прогон

Команды существующих скриптов:

```text
python ml/cut_fragments.py --input "Sound sample" --output <папка фрагментов>
python ml/generate_spectrograms.py --input <папка фрагментов> --output <папка спектрограмм> --manifest <manifest_fragments.csv>
python ml/validate_dataset.py --manifest <manifest_fragments.csv> --spectro <папка спектрограмм>
```

| | |
|---|---|
| Файлов на входе | 14 |
| Файлов, давших фрагменты | 13 |
| Фрагментов | 258 |
| Длина фрагмента | 2.5 с |
| Каналы фрагмента | 1 |
| Частота | 44100 Гц |

Один файл короче окна анализа (1.559 с) и не дал фрагмента: неполное окно скрипт не сохраняет. Остальные фрагменты проверены по длительности в манифесте и по заголовку wav: ровно 2.5 с.

Параметры окна прочитаны из `config/window_config.yaml`: FFT 1024, hop 512, Hann, log-mel, верхняя частота 22050 Гц.

## validate_dataset

Проверка нарезки прошла.

- Конфиг рядом со спектрограммами совпал с `config/window_config.yaml`.
- Спектрограмм 258, столько же, сколько фрагментов.
- Размер спектрограммы `(128, 216)`, кадры совпали с hop окна.
- Все фрагменты равны длине окна анализа (2.5 с).

Итог скрипта: пройдено 4, предупреждений 2, ошибок 2, строка `[FAIL]`. Ошибки — ручные пункты «Датасет версионирован (DVC)» и «Лицензии проверены». Этот пакет их не закрывает: строка лицензий в `doc_v2/IMPLEMENTATION_PLAN.md` §8 остаётся открытой. Предупреждения — нет разметки bird/no_bird и нет типов позитивов.
