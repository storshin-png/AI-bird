## Сделать

На пустой карте показать слой датчиков из синтетического GeoJSON, который лежит в `web/`. Цвет точки — по статусу датчика. Клик открывает карточку устройства. На малом масштабе точки кластеризуются.

Виды по-прежнему не зашивать. `loadSpecies()` остаётся пустым списком, комментарий про будущий `GET /species` не менять на выдуманный адрес.

## Границы

Фильтр по датчику и времени, очередь Unknown, экспорт, тепловая карта, пеленги и треки не входят. Анимация миграции не входит. Каталога `cloud/` в diff нет. Латинских названий птиц в `web/src` нет.

## Проверка

Сборка командой из `web/README.md`:

```text
npm install
npm run build
```

Поиск по `web/src` не находит латинских названий птиц. Один pull request, описание по шаблону GitHub.
