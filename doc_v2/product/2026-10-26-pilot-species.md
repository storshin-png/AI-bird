# Список видов пилота

Дата: 2026-10-26
Статус: принято CEO
Источник: `data/species/species.csv`
Журнал: `IMPLEMENTATION_PLAN.md` §8

## Для кого

B2B-клиент видит эти имена на карте, в карточке события, в CSV, GeoJSON и PDF. Орнитолог сверяет с ними ручную проверку. Backend берёт файл как seed таблицы `species`. NN3 называет вид только из этого списка.

## Какое поведение верное

В файле 50 видов, у каждой строки `in_pilot_50=true` и `red_book_flag=false`. Это полный список имён пилота.

Вид на событии — один из этих 50, если порог NN3 пройден. Иначе событие остаётся Unknown и идёт в ручную проверку. Ближайший класс из списка вместо Unknown не подставляется.

Алерт краснокнижного вида на этом списке не срабатывает: флаг у всех пятидесяти строк `false`.

Сезон пилота 11.01.2027–05.02.2027 в окрестностях Магнитогорска. Часть имён в эти недели молчит. Пустая карта по такому имени — ожидаемый вид пилота, а не повод дополнять список.

## За рамкой MVP

Больше 50 видов, глобальный список BirdNET, видовая классификация на устройстве, смена окна анализа, API и схемы БД.
