### 🎯 Рекомендация для команды

**Для MVP-пилота (Спринты 1–8, 5 датчиков, 4 недели)** — однозначно **Вариант 2**. Он попадает в целевой BOM $150–$170 из `MVP_SPEC`, закрывает все критические риски (ошибка ориентации, влага в портах) и достаточен для получения LOI от B2B-клиента.

**Вариант 1** имеет смысл только для **1–2 стендовых прототипов** в Спринте 1–2, чтобы отладить прошивку и NN1 до сборки партии.

**Вариант 3** — это **v1.1 после Seed-раунда** ($500K–$1M). Он нужен, когда:
- B2B-клиент (ветропарк/заповедник) требует SLA по надежности;
- Локации экстремальные (побережье, высокогорье, тропики);
- Нужна юридическая защита данных (точность DOA подтверждена авто-калибровкой).

**Важно по 3D-печати:** Для всех вариантов критична **постобработка**. PETG/ASA/PC на FDM имеют микрощели между слоями — без пропитки/покраски IP67 не получить. Для Варианта 3 обязательно использовать **эпоксидную пропитку** или печать с минимальной высотой слоя (0.12 мм) + 4 периметра + 30% infill. Альтернатива — SLA-печать из UV-стойкой смолы (дороже, но лучше герметичность «из коробки»).
