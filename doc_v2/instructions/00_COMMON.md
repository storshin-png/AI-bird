# Общие правила для всех участников

Репозиторий: https://github.com/storshin-png/AI-bird.git
Порядок работы: `../COLLABORATION.md`
Текущее направление: `../directions/2026-10-07-prep.md`

## Перед первой задачей

1. Принять приглашение в GitHub и подтвердить ту почту, которую назвали при назначении роли.
2. Клонировать репозиторий: `git clone https://github.com/storshin-png/AI-bird.git`
3. Прочитать направление, свою инструкцию и ТЗ своего агента.
4. Агенту отдавать ТЗ и перечисленные в нём файлы. Весь MVP одним сообщением не ставить.

## Ветка и запрос

```text
git checkout main
git pull
git checkout -b <зона>/<короткая-задача>
```

После работы агента прочитать diff. В `main` пушить эту ветку и открыть pull request. Шаблон запроса заполнить полностью. Описание «сделал агент» без чеклиста CEO возвращает.

Проверка `ci` должна быть зелёной. Мерж делает CEO.

## Что остаётся у человека

Агент пишет файлы. Человек слушает golden set и спорные фрагменты, ставит датчик, принимает закупку, подписывает лицензию и локацию, решает, что запрос готов к CEO.

В репозиторий не попадают `.env`, виртуальное окружение, сырое аудио и файлы Word с префиксом `~$`.
