## Зона

Только `web/`. Эндпоинты, схема БД и обработка звука живут в `cloud/`. Если для экрана не хватает поля, это отдельный запрос к Backend с пометкой `contract`, а не правка сервера из ветки карты.

Скрытие кнопки по роли — подсказка интерфейса. Отказ сервера на чужой роли проверяет Backend.

## До 16.10.2026

Пакет `web/map-shell` по ТЗ агента: каркас приложения, пустая карта, пустое состояние. Список видов в код не зашивать. Пока `GET /species` нет, экран показывает пустое состояние и тип данных, совпадающий с будущим ответом.
