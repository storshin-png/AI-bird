## Пакет сейчас: единый конфиг в скриптах

Ветка: `ml/window-config`

В `cut_fragments.py`, `generate_spectrograms.py`, `validate_dataset.py`:

- убрать копию словаря параметров окна;
- читать `config/window_config.yaml`;
- длина фрагмента, sample rate, FFT, hop, окно и представление берутся из этого файла.

Во всех скриптах `ml/`:

- убрать жёсткие пути вида `D:/bird_audio`;
- вход и выход задаются аргументами командной строки;
- `label_manifest.py` тоже переводится на аргументы, без прописанного диска.

Нарезка моно для открытых архивов остаётся допустимой. Для файлов с 4 каналами канал не смешивать в один без явного флага, по умолчанию хранить каналы.

Добавить в `ml/README.md` пример вызова нарезки и генерации спектрограммы.
